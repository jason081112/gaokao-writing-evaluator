## 项目亮点

- **双轨评分引擎**：内容与语言权重可调，严格 / 标准 / 宽松三档输出，附分数漂移校准机制，确保跨模型评分一致性
- **语义句链分析**（灵感来自高中英语老师 Liu X.）：将续写内容拆解为 A1–A5、B1–B5 逻辑节点，逐节点评估与原文融洽度、情节合理性、语言准确性
- **防稀疏架构**：核心规则首尾锚定，长材料渐进式披露，多轮上下文具备复述锚点，降低长提示词注意力稀疏风险
- **可迁移范文生成**：保留学生原有合理构思，加粗标注 3–5 处可迁移表达，语言自然、不堆砌生僻词

## 适用场景

- 高中生自测高考英语作文，了解当前分数区间与提分方向
- 教师批改作文时作为辅助评分与点评工具
- 英语学习者对比学生原句与范文改写，积累可迁移表达
- 开发者研究 Agent Skill 结构，作为 Complex Skill 的参考实现

## 当前能力

- **自动识别作文类型**：应用文 / 读后续写 / 两者均有
- **三档评分**：严格、标准、宽松三档分数 + 推荐分，附漂移校准说明
- **逐项点评**：应用文逐项对照要点，读后续写逐节点分析情节链
- **情节链断裂标注**：人物矛盾、转折无铺垫、伏笔无呼应等，明确标出断裂位置与改进方向
- **语言错误分层**：标注影响程度（轻微 / 中度 / 严重）和模板化表达
- **对话/情感/伏笔专项**：检查续写对话比例、情感曲线、与原文伏笔呼应
- **前三大问题 + 最小修改提档**：不只列问题，还给出优先修改顺序
- **高分范文**：保留学生原有合理构思，加粗标注 3–5 处可迁移表达
- **改写对照表**：学生原句 → 问题类型 → 影响程度 → 范文改写
- **总分汇总表**：多篇作文汇总在同一张表内

## 快速开始

本 Skill 提供两种使用方式，你可以根据自己的环境和习惯选择。

### 方式一：作为 Agent Skill 加载

适用于支持 `SKILL.md` 格式的 Agent 客户端（如 RikkaHub、Claude Code 等）。

```bash
git clone https://github.com/jason081112/gaokao-writing-evaluator.git
```

克隆后，在客户端中加载该技能。具体加载方式请参考对应客户端的文档。

### 方式二：直接复制提示词

考虑到 Agent Skill（智能体技能包）这类进阶玩法门槛较高、上手的高中生还不多，你可以直接使用根目录下的 [PROMPT.md](./PROMPT.md) 文件。它包含了完整的评卷指令，无需任何配置。

使用方法：

1. 打开 PROMPT.md，全选复制。
2. 粘贴到任何支持长文本的 AI 对话窗口，例如 DeepSeek、ChatGPT、Kimi、豆包、通义千问等。
3. 在同一个对话中，直接提交你的作文材料即可。

```
【题目要求】……
【学生作文】……
【读后续写原文】……
【首句1】……
【首句2】……
```

Agent 第一动作会输出复选栏，你回复编号或"全选"后，开始生成评卷报告。

注：此方式依赖客户端的上下文长度，建议使用支持较长上下文的模型。

## 输出模块

| 分类 | 模块 |
|---|---|
| 评分 | 三档评分 + 推荐分、漂移校准、跑题兜底 |
| 点评 | 逐项/逐节点点评、情节链断裂、对话/情感/伏笔、语言错误影响程度、模板化表达 |
| 生成 | 前三大问题、最小修改提档、高分范文、改写对照表 |
| 汇总 | 总分汇总表、多篇横向对比 |
| 输出控制 | 精简模式、标准模式、详细模式 |

## 评分标准

应用文满分 15 分，读后续写满分 25 分，均按五档给分。词数不足或超标、书写差影响交际，按新高考细则扣分或降档。详细档位表见 `references/` 目录。
