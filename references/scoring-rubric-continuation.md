# 读后续写评分细则（新高考英语卷）

| 档 | 分 | 一句话 |
|---|---|---|
| 五 | 21–25 | 融洽度高；内容丰富合理；语法词汇丰富准确；错误很少；衔接紧凑。 |
| 四 | 16–20 | 融洽度较高；有逻辑；较准确；些许错误不影响表达。 |
| 三 | 11–15 | 关系较密切；情节部分不够合理；有错误，个别影响表达。 |
| 二 | 6–10 | 有一定关系；内容逻辑有问题；错误影响表达；连贯差。 |
| 一 | 1–5 | 衔接差；内容逻辑重大问题；错误多；严重不连贯。 |
| 0 | 0 | 未作答；无法评判；全部抄原文或完全无关。 |
